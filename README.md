# 汪汪队大冒险 · Paw Adventure Valley

一款用纯 HTML/CSS/JavaScript（单文件、无依赖）开发的儿童向像素风开放世界游戏。灵感来自《汪汪队立大功》与《星露谷物语》——在冒险湾里切换救援犬、开专属赛车、接救援任务、跟居民互动、推进主线剧情。

直接用浏览器打开 `index.html` 即可游玩，无需安装任何东西。

## 玩法亮点

- **10 只可切换救援犬**：阿奇🔍、毛毛🔥、小砾🪨、路马🌊、灰灰♻️、天天🪽、珠珠❄️、丛林🧭（寻宝）、海宝📡（声呐）、甜甜💗（急救鼓舞），每只有专属技能、头像和编号赛车。
- **专属赛车 + 计时赛**：按 R 开出配套赛车，赛车场里跑计时赛刷新纪录。
- **开放世界地图**：小镇中心（蓝色总部大楼、爪印广场）、杰克山（风车、矿洞、滑雪场）、由美农场、冒险湾海滩与海湾、卡洛斯丛林营地、沙漠峡谷等，10 个快速旅行站。
- **室内系统**：17 栋建筑都能按 E 进屋，内含手绘家具软装。
- **主线剧情《冒险湾的秘密》**：12 幕 5 章 + 终章，登上神秘岛拿到大宝藏。
- **8 个居民委托 + 45 个 NPC**：盟友、会走动的动物居民、以及 10 个"捣乱但无害"的儿童向反派。
- **存档系统**：进度自动保存与回放。

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 / WASD | 移动 |
| 数字键 / Tab | 切换队员 |
| R | 召唤/收起赛车 |
| E | 互动（进门、接任务、对话、购物等）|
| J | 打开冒险日志 |
| M | 打开大地图 |
| 空格 | 使用当前队员技能 |

## 文件说明

- `index.html` — 最终版游戏（可直接游玩）
- `汪汪队大冒险.html` — 同上，保留原始中文文件名
- `game_check.js` — 自动化测试脚本
- `汪汪队大冒险_v2.html` ~ `_v6.html` — 历史迭代版本，记录设计演进过程

## 技术

单个 HTML 文件，内联 CSS + JavaScript，Canvas 渲染，所有像素美术（角色头像、赛车、动物、建筑、道具）均由代码程序化绘制，无外部图片资源。
